Below is Python code which can convert a .pdf into images
```py
import fitz
import os

pdf_path = "input.pdf"
out_dir = "output_images"
zoom = 2
image_prefix = "page_"

doc = fitz.open(pdf_path)

os.makedirs(out_dir, exist_ok=True)

paths = []

for pno in range(doc.page_count):
	page = doc[pno]

	mat = fitz.Matrix(zoom, zoom)

	pix = page.get_pixmap(matrix=mat, alpha=False)

	out_path = os.path.join(out_dir, f"{image_prefix}{pno + 1}.png")
	pix.save(out_path)

	paths.append(out_path)
```

Below is Python code which zooms into a picture. You can also use this logic on the output of the `fitz` .pdf snippet
```py
from PIL import Image
import numpy as np

in_path  = "input.png"
out_path = "output_zoom.png"

zoom_factor = 3.0

box_xyxy = (300, 200, 900, 650)

img = Image.open(in_path).convert("RGB")
w, h = img.size

x1, y1, x2, y2 = box_xyxy

x1 = max(0, min(x1, w))
x2 = max(0, min(x2, w))
y1 = max(0, min(y1, h))
y2 = max(0, min(y2, h))

if x2 <= x1 or y2 <= y1:
	raise ValueError(f"Invalid crop box")

crop = img.crop((x1, y1, x2, y2))
cw, ch = crop.size

out_w = int(cw * zoom_factor)
out_h = int(ch * zoom_factor)

zoomed = crop.resize((out_w, out_h), resample=Image.Resampling.LANCZOS)
zoomed.save(out_path)
```
