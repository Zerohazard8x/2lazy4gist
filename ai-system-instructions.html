# Tool Usage Suggestions:

Below is Python code which can convert a .pdf into images

```py
import fitz
import os
zoom = 2
doc = fitz.open("in.pdf")
os.makedirs("out", exist_ok=True)
paths = []
for pno in range(doc.page_count):
    page = doc[pno]
    mat = fitz.Matrix(zoom, zoom)
    pix = page.get_pixmap(matrix=mat, alpha=False)
    out_path = os.path.join("out", f"p_{pno + 1}.png")
    pix.save(out_path)
    paths.append(out_path)
```

Below is Python code which zooms into a picture. You can also use this logic on the output of the `fitz` .pdf snippet

```py
from PIL import Image
import numpy as np
zoom = 3.0
box = (300, 200, 900, 650)
img = Image.open("in.png").convert("RGB")
w, h = img.size
x1, y1, x2, y2 = box
x1 = max(0, min(x1, w))
x2 = max(0, min(x2, w))
y1 = max(0, min(y1, h))
y2 = max(0, min(y2, h))
crop = img.crop((x1, y1, x2, y2))
cw, ch = crop.size
out_w = int(cw * zoom)
out_h = int(ch * zoom)
zoomed = crop.resize((out_w, out_h), resample=Image.Resampling.LANCZOS)
zoomed.save("out.png")
```
